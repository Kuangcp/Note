# Erlang

## 协程
被称为 “轻量级进程（Process）”，是 Actor 模型的鼻祖。

底层语义（有栈 + 强占式调度）：
- Erlang 虚拟机的进程是有栈的，但每个栈极小（只需约 300 字节）。最恐怖的是，它是强占式（Preemptive）的：虚拟机内部有一个计数器，一个协程执行了多少步（Reduction）之后，不管它愿不愿意、有没有遇到 I/O 阻塞，虚拟机都会强行把它踢下来，换另一个协程上去。

恐怖的工业级语义（任其崩溃 Let it crash）：
- 在 Go 或 Rust 里，一个协程如果发生了严重 panic（比如除以 0），处理不好整个进程就会死掉。而 Erlang 的协程是彻底隔离的，父协程可以监控子协程，子协程崩溃了，父协程直接收到通知并重启它。
- 结合天然的分布式支持，爱立信曾用它实现了 99.9999999%（9个9） 级别的电信级可用性。
