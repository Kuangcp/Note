# CSharp

## 协程
现在风靡全球的 async/await 语法，其实是 C# 团队在 2012 年最早发明并引入现代编程语言的（随后被 JS、Python、Rust 疯狂借鉴）。

底层语义（基于 Task 的状态机）：
- C# 的协程同样是无栈的。编译器会把 async 方法编译成一个实现了 IAsyncStateMachine 接口的结构体。

开发体验：
- C# 的开发体验非常接近 Go。它的调度器非常聪明，默认会将任务分发到多线程池（ThreadPool）。你只需要写 await，底层的线程切换、上下文恢复全部由 .NET 运行时（CLR）丝滑地搞定。
- 它是目前在“无栈协程的极致性能”与“面向对象语言的顺滑体验”之间平衡得最好的语言。
